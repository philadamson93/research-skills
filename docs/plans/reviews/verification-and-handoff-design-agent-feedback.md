## Suggested Revisions
- Add a "Migration of existing `/review-plan` lenses" subsection under Approach or Files to Modify that names each current lens and where it moves.
- Expand the `claude_ops.md` bullet with the exact new `Handoff phasing / decomposition` markdown block to insert under the Plan Document Structure template.
- Add a concrete complexity classifier: for example, simple = one handoff, one repo, no decision gates, no banked prior SHA; complex = any cross-repo SHA, multiple handoff phases, class-2 decision gates, bank/un-bank logic, destructive writes, or multi-target bundling.
- Define the phasing sub-section's required fields so `/plan-handoff-readiness` can check more than "section exists."
- Tighten `/vm-handoff` scope language: canonical spec describes plan-time batching strategy; `/vm-handoff` owns rendering, tiered sign-off, Expected/Stop enforcement, deviation class handling, and supersede mechanics.
- Rephrase the per-repo checklist claim to avoid implying all checklists already use `Recipe / Sample-size / Diff-against` headings.
- Add dogfood acceptance criteria that exercise both authoring and audit, and specifically fail if the new pass merely duplicates old `/review-plan` findings.
